FIRST PRINCIPLES · ARCHITECTURE BLUEPRINT

超级个体的 Agent 协作系统
不是一个大模型，而是一支分层数字团队

◆ 第一性原点

超级个体唯一不可再生的资源是 注意力。 系统全部目标：把注意力只投在 高价值决策与核心专业交付，其余工作按风险等级分流给 Agent； 自动化不是越自动越好，而是 主人自主选择每一类任务的信任等级。

01

三层 Agent 协作架构 · 总览

自上而下：主人下达意图 → L0 管家调度风控 → L1 业务专家生成方案 → L2 任务实例跟踪执行 → 共享底座提供唯一可信数据源 → 外部触点受控触达。

02

双运行模式 · 陪跑 vs 全自动

全局默认陪跑；主人对低风险场景单独授权全自动。任何时候一键熔断，全部退回陪跑。

陪跑模式 默认安全

Agent 整理、起草、建议、提醒；所有对外输出与关键变更必须主人确认。

  • 生成初稿 / 方案 / 摘要，全部进审核队列
  • 不主动对外发送消息
  • 不修改核心业务数据
  • 里程碑验收、报价、合同永远走这里
  • 是训练 Agent 的过程：主人的每次修改都在沉淀事实库

全自动模式 受控信任

围栏内自主执行，事后知会；出圈立刻降级为陪跑并告警。

  • 先配围栏规则，没围栏不能开
  • 范围 / 否决 / 时间 / 阈值四类规则
  • 动作留日志，可一键回滚
  • 典型场景：自动建档、打标签、归档、节点提醒
  • 支持全局开关 + 单场景授权 + 紧急熔断三级控制
03

任务风险分级 · 决定执行模式

L0 管家在任务生成时自动打 T 标签，标签是调度的第一判断依据。

T1 · HIGH

高风险不可逆

报价、合同、服务范围变更、承诺交付周期、核心方案定稿、重要合作邀约

强制陪跑 · 禁止全自动
T2 · MID

中风险标准动作

标准 FAQ 回复、固定回访话术、客户建档、节点提醒、标签打标

默认陪跑 · 围栏内可全自动
T3 · LOW

低风险内部

知识检索、纪要整理、素材改写、待办草稿、周报汇总、文件归档

默认全自动 · 事后知会
T4 · SYS

系统后台

日志落盘、向量库更新、定时简报、围栏巡检、超时检测

常驻全自动
04

一次任务的 Agent 全程协作 · 七步链路

以"主人接了一个客户咨询项目"为例：从一句自然语言指令，到 L2 任务树落地、产出物归档。

STEP 01
主人
下达意图

自然语言："帮我承接 XX 客户品牌咨询项目，交付诊断方案。"

STEP 02
L0 管家
识别与分级

解析意图，判定 T1，路由给项目 Agent，读取围栏与当前模式。

STEP 03
L1 项目 Agent
规划方案

读事实库同类模板，拆出项目→里程碑→迭代→原子任务树，含产出物与验收标准。

STEP 04
主人
审核规划

T1 强制陪跑。主人通过 / 修改 / 驳回；通过后才实例化 L2 任务树。

STEP 05
L2 任务树
按模式执行

T3 原子任务自动跑；T2 围栏内自动、出圈转审核；T1 节点到点告警主人。

STEP 06
L0 管家
围栏校验 & 触出

所有对外动作二次校验围栏；不通过降级陪跑；通过后经外部触点发出。

STEP 07
底座
沉淀反馈

产出物版本化入库；主人审核意见反哺事实库与围栏建议；里程碑验收聚合成果。

05

L2 任务树结构 · 模式继承规则

模式自顶向下继承：项目 → 里程碑 → 迭代 → 原子任务。单个原子任务可单独覆盖，例如"归档资料"独立开全自动。

PROJECT · L2.0

项目

承载客户交付或个人专项；总周期、SLA、总产出清单。

  • 终验 T1 强制陪跑
  • 关联客户档案
  • 整体模式默认陪跑
MILESTONE · L2.1

里程碑（关口）

阶段成果交付点；验收不通过则阻塞后续迭代。

  • 需求确认 / 初稿 / 定稿 / 交付验收
  • 到点自动触发验收
  • 聚合本节点全部产出物
ITERATION · L2.2

迭代（时间盒）

默认 1–3 天短周期，聚焦一组目标。

  • 启动简报
  • 阻塞 / 延期实时告警
  • 收尾小结，未完成项滚入下一轮
TASK · L2.3

原子任务

最小执行单元；绑定责任人（Agent / 主人）、产出物、依赖。

  • 状态：待安排→进行中→待验收→完成
  • 前置依赖阻塞时告警
  • 可单独覆盖模式
06

产出物管理 · 所有 Agent 输出统一治理

产出物仓库独立于事实库：事实库是"可信知识"，产出物仓库是"Agent 草稿与历史"。每一条强制携带元数据。

关联 L2 节点　产出物可挂在项目 / 里程碑 / 迭代 / 原子任务四级；里程碑验收页自动聚合并展示。
状态机　草稿 → 已审核 → 已发送 / 驳回；每次修改自动升版本，支持回滚任意历史版本。
溯源字段　Agent 来源 · T 等级 · 模式 · 引用知识片段 ID · 审核人 · 围栏触发记录。
