> 来源：`https://cleanshot.com/pricing` 实测提取

## 2. 字体体系 (Typography)

### 2.1 字体族

| 用途 | 字体栈 |
|------|--------|
| 正文 / 标题 | `"Google Sans Flex", "SF Pro Display", "SF Pro Text", -apple-system, "Segoe UI", "PingFang SC", "Helvetica Neue", Helvetica, Arial, sans-serif` |
| 等宽（代码） | `ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace` |

> 参考站使用 Google Sans Flex（Web Font）；本站不加载外部字体，回退到系统字体栈。

### 2.2 字号层级（实测值，格式：字号 / 行高）

| Token | 桌面 ≥1024px | 字重 | 字间距 | 用途 |
|-------|--------------|------|--------|------|
| Display（H1） | `60px / 66px` | 600 | `-0.02em` | 页面主标题 |
| Section（H2） | `40px / 48px` | 600 | `-0.02em` | 区块标题 |
| 文档小标题（H3） | `24px / 29px` | 600 | `-0.02em` | 卡片/文档标题 |
| 正文大号 | `18px / 30px` | 450 | `0.01em` | 营销段落 |
| 正文 | `16px / 24px` | 400 | normal | 列表、聊天、编辑器正文 |
| 按钮 / 导航 | `15px / 24px` | 550 | `0.01em` | 按钮、导航项、表单标签 |
| 列表主文 | `14px / 21px` | 400 | normal | 高密度列表 |
| 脚注 / 元信息 | `13px / 18px` | 400 | normal | 计数、附件元信息、说明 |

### 2.3 字重

| 名称 | 值 | 用途 |
|------|-----|------|
| Regular | 400 | 正文、列表、脚注 |
| Medium | 500 | 按钮、导航、链接操作 |
| Semibold | 600 | 所有标题、面板/列表头 |

> 参考站正文为 450、按钮为 550（可变字体）；本站回退为 400 / 500 / 600 三档。

### 2.4 排版规则

| 规则 | 值 |
|------|-----|
| 大标题字距 | `-0.02em` |
| 按钮/导航字距 | `0.01em` |

## 5. 层级与阴影 (Elevation)

参考站不使用硬边框建立层级，而是「层叠柔光 + 1px 发丝环」：

| 用途 | 值 |
|------|-----|
| 卡片 | `0 7px 20px -8px rgb(22 22 24 / 2%), 0 29px 33px -4px rgb(22 22 24 / 2%), 0 22px 30px -8px rgb(22 22 24 / 5%), 0 0 0 1px rgb(22 22 24 / 6%)` |
| 次级按钮 / 图标按钮 | `0 2px 6px -1px rgb(22 22 24 / 20%), 0 0 0 1px rgb(22 22 24 / 16%)` |
| 主 CTA | `0 2px 6px -1px rgb(4 24 85 / 28%), inset 0 6px 14px 0 rgb(66 174 247 / 48%)` |
| 浮层 / 弹窗 | `0 16px 40px -12px rgb(22 22 24 / 20%), 0 0 0 1px rgb(22 22 24 / 8%)` |

- 卡片底色 `#ffffff`，落在 `#f7f7f8` 画布上。
- 深色 CTA 区块使用近黑渐变（`#0b0b0d` → `#1a1a20`）承载白色标题与白色按钮。
- 强调卡片可使用粉 `#ffe9ec → #ffd9df`、蓝 `#e3f1ff → #cfe6ff`、紫 `#ffe6f0 → #e9d8ff` 的柔和渐变。

## 6. 控件规范

| 控件 | 规格 |
|------|------|
| 主按钮 | 品牌蓝实底、白字、`14px` 圆角、高 `40/48px`、主 CTA 阴影 |
| 次按钮 | 白底 + `rgba(22,22,24,0.16)` 环 + 次级阴影、主文字色 |
| 幽灵按钮 | 透明底、主文字色、悬停 `rgba(22,22,24,0.04)`、`14px` 圆角 |
| 输入框 | 白底、`1px` `rgba(22,22,24,0.12)` 描边、`14px` 圆角、高 `40px` |
| 徽标 / chip | `rgba(22,22,24,0.04)` 底、三级文字、`14px` 圆角 |
| 导航项 | 高 `40px`、`15px/550`、`14px` 圆角；选中态为蓝染底 + 品牌蓝文字 |
| 焦点态 | 2px 品牌蓝轮廓，偏移 2px |

### 6.1 按钮尺寸档位

- 统一使用 Nuxt UI `UButton` 默认尺寸档位（`xs` / `sm` / `md` / `lg` / `xl`），默认 `md`。
- 页面只传 `size`，不写死高度与内距；`app/app.config.ts` 只配置主题配色，不覆写组件尺寸。
- 圆角走全局 `--ui-radius`（`14px`）。
- 同一容器内按钮同档：弹窗页脚用默认 `md`，卡片内行内操作用 `xs`。
- 禁用态不透明度 `50%`，焦点态沿用 Nuxt UI 默认焦点轮廓。

## 7. 响应式断点

| 断点 | 用途 |
|------|------|
| `≤767px` | 手机：单列堆叠，正文 14/21 |
| `768px–1023px` | 平板：双列 |
| `1024px–1359px` | 小桌面：双列，画布内边距收紧 |
| `≥1360px` | 桌面：工作台五列并排（4×280px 固定 + 会话列自适应） |

> 断点为本站落值；参考站未公开其媒体查询阈值。
